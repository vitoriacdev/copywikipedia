# 🐉 The Empyrean Encyclopedia

An interactive encyclopedia dedicated to *The Empyrean* fantasy book series by Rebecca Yarros.

## 📖 About the Project

The Empyrean Encyclopedia is a web development project created to organize information about Rebecca Yarros's fantasy series in one place. Inspired by online encyclopedias, the website provides an overview of the books, characters, fictional world, dragon system, and screen adaptation.

The project aims to present information in a clear and organized way while providing a simple browsing experience for readers and fans of the series.

This project was developed as part of my learning journey in Software Engineering, with a focus on practicing HTML and CSS.

## ✨ Features

- **Series Overview:** An introduction to *The Empyrean* universe.
- **Author Biography:** Information about Rebecca Yarros and her writing career.
- **Plot Summary:** An overview of the main storyline.
- **World and Setting:** Information about Navarre and Basgiath War College.
- **Dragon System:** An introduction to dragons, bonds, and signets.
- **Character Profiles:** Information about the main characters, students, and instructors.
- **Book Guide:** Information about the books in the series, organized by publication order.
- **Screen Adaptation:** A section about the television adaptation.
- **Interactive Table of Contents:** Navigation links that take readers directly to specific sections.
- **Expandable Content:** Collapsible sections created with HTML to organize additional information.
- **References and External Links:** Sources for further reading and research.

## 🛠️ Technologies

The project uses the following technologies:

- **HTML5:** For the structure and organization of the website's content.
- **CSS3:** For styling, layout, and visual presentation.

No JavaScript framework or external CSS framework is required.

## 🚀 How to Run the Project

You can view the website locally by following these steps:

1. Clone or download this repository.
2. Open the project folder on your computer.
3. Open `index.html` in your web browser.
4. Explore the different sections of the encyclopedia.

You can also use Visual Studio Code with the Live Server extension to preview changes while developing the website.
